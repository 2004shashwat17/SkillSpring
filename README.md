# SkillSpring - Frontend Demo


This is a small React + Vite demo frontend implementing:

- Home page with hero section
- Courses page with grid of 6 courses
- Course detail page with description, pricing options (hour/day/month), demo image, contact and "Pay Now" button
- Login page

How to run (Windows PowerShell):

1. Install dependencies

```powershell
cd "c:/Users/91828/Desktop/dhananjay course"
npm install
```

2. Start dev server

```powershell
npm run dev
```

Open the dev server URL printed by Vite (usually http://localhost:5173).

Notes:
- This is a frontend demo only. "Pay Now" is a placeholder and shows a demo alert.
- Images are placeholders from via.placeholder.com; replace them with real images if you have them.
